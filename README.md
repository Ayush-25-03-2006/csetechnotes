# 📚 CSENotes — Learn Computer Science

CSENotes is a free educational platform built for Computer Science and IT students.

The platform provides organized study materials, notes, PDFs, quizzes, and learning resources to help students learn Computer Science concepts in one place.

🌐 Live Website: https://csenotes.vercel.app/

---

## 🚀 Features

* 📚 Subject-wise Computer Science Notes
* 📄 PDF Study Materials
* 📝 Interactive MCQ Quizzes
* 💻 Programming Resources
* 🗂️ Organized Learning Content
* 📱 Responsive Design
* 🌙 Modern User Interface
* ⚡ Fast and Lightweight
* 🤖 AI-powered learning through Chakravyu AI

---

## 📝 Quiz Platform

CSENotes includes subject-based MCQ quizzes that allow students to practice important concepts and test their knowledge.

The quiz section is useful for:

* Semester examination preparation
* Concept revision
* MCQ practice
* Self-assessment
* Competitive examination preparation

# 🤖 Chakravyu AI

CSENotes is being enhanced with **Chakravyu AI**, an AI-powered study assistant designed to make Computer Science learning more interactive.

Students can use Chakravyu AI to:

* 💬 Ask Computer Science questions
* 🧠 Understand difficult concepts
* 📖 Get explanations
* 💻 Get programming assistance
* 🔍 Explore technical topics
* 🎓 Use AI as a personal study assistant

🌐 Chakravyu AI: https://chakravyuai.vercel.app/

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the project

```bash
cd CSENotes
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173/
```

## 🎯 Project Objective

The goal of CSENotes is to make Computer Science education easier and more accessible.

Instead of searching for study materials across multiple platforms, students can use CSENotes to find notes, PDFs, quizzes, and learning resources in one place.

The integration of Chakravyu AI adds an interactive AI-based learning experience to the platform.
